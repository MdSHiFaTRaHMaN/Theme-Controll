# ⚡ Shopify Multi-Store Remote Controller & Central Dashboard

এই সিস্টেমটি দিয়ে আপনি আপনার ৫-৭টি (বা তার বেশি) Shopify স্টোরে **লগইন না করেই** যেকোনো স্টোরের হোমপেজকে **🟢 Main Live Website** অথবা **⏳ Luxury Launch Soon / Coming Soon Page**-এ রিমোটলি ১ ক্লিকে পরিবর্তন করতে পারবেন।

## 📁 ১. আপনার প্রতিটি Shopify Theme-এ কিভাবে কানেক্ট করবেন?

প্রতিটি Shopify স্টোরে শুধুমাত্র **১টি ফাইল** যোগ করতে হবে:

### ধাপ ১: Snippet ফাইল তৈরি করুন
1. Shopify Admin-এ যান: **Online Store &rarr; Themes &rarr; Edit code**
2. **Snippets** ফোল্ডারে ক্লিক করে **Add a new snippet** নির্বাচন করুন।
3. নাম দিন: `store-mode-controller.liquid`
4. [store-mode-controller.liquid](file:///c:/SinghClo/snippets/store-mode-controller.liquid) ফাইলের পুরো কোড কপি করে পেস্ট করে Save করুন।

### ধাপ ২: `layout/theme.liquid`-এ ১ লাইন কোড বসান
`layout/theme.liquid` ওপেন করে `<body ...>` ট্যাগের ঠিক নিচে নিচের লাইনটি বসান:

```liquid
{% render 'store-mode-controller', store_id: 'singhclo' %}
```
*(অন্যান্য স্টোরের ক্ষেত্রে `singhclo`-এর জায়গায় সেই স্টোরের আইডি যেমন `store2`, `store3` ইত্যাদি বসাবেন)*

## 🎛️ ২. সেন্ট্রাল ড্যাশবোর্ড চালু করার নিয়ম

### অপশন A: আপনার কম্পিউটারে লোকালভাবে চালানো (১ সেকেন্ডে চালু)
1. টার্মিনাল বা কমান্ড প্রম্পটে যান:
```bash
cd dashboard
node server.js
```
2. ব্রাউজারে ওপেন করুন: `http://localhost:3000`

### অপশন B: সম্পূর্ণ ফ্রিতে ক্লাউডে হোস্ট করা (24/7 Live Dashboard)
ড্যাশবোর্ড ফোল্ডারটি আপনি যেকোনো ফ্রি হোস্টিংয়ে ডিপ্লয় করতে পারেন:
- **Vercel** (Recommended: 1-click deploy)
- **Render.com** (Free Node web service)
- **Glitch / Railway / Replit**
